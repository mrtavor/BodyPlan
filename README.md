# BodyPlan & CalorieSync 🚀

Сучасний прогресивний веб-додаток (PWA) для точного біометричного розрахунку тіла, розумного планування дієти з **калорійним циклуванням (будні / вихідні)**, швидкого щоденного обліку калорій (сумісно з **YAZIO**), підрахунку спаленого підшкірного жиру в грамах та синхронізації через **Google Auth** і **Google Fit**.

---

## ✨ Основні можливості

1. **Комплексний Біометричний Калькулятор:**
   - Розрахунок відсотка жиру за офіційною формулою ВМС США (US Navy Body Fat).
   - Точний розрахунок сухої м'язової маси та жирової тканини у кілограмах.
   - Розрахунок базового метаболізму (**BMR**) за формулою Кетча-МакАрдла / Міффліна-Сан Жеора.
   - Повна добова витрата енергії (**TDEE**) з урахуванням професії, кроків та тренувань.

2. **Гнучкий Планувальник Дієти & Калорійний Цикл:**
   - Вибір мети: *Схуднення зі збереженням м'язів (High Protein)*, *Звичайне схуднення*, *Підтримка форми / рекомпозиція*, *Чистий набір м'язової маси*.
   - **Калорійне циклування:** налаштування більшої кількості калорій на вихідні (Пт, Сб, Нд) та дефіциту в будні — при 100% збереженні точного тижневого дефіциту!
   - Аналіз безпеки та реалістичності темпів схуднення (порівняння з фізіологічною нормою 0.5–1% ваги на тиждень).
   - Розрахунок індивідуальної норми білка (г/кг), жирів, вуглеводів, води та клітковини.

3. **Щоденник Дня (Daily Tracker):**
   - **Швидке введення калоражу:** легко вписати підсумкову цифру зі свого додатка підрахунку (**YAZIO** тощо).
   - Ранкове зважування, облік кроків, тренувань та випитої води.
   - **Лічильник спаленого жиру:** показує точну кількість спалених грамів чистого жиру за кожен день на основі формули: $\frac{\text{Дефіцит}}{7.7}$.
   - Кнопка **«Відмітити день як пройдений»** з анімацією конфеті та збереженням стрику 🔥.

4. **Інтерактивна Графічна Аналітика:**
   - Графік споживання калорій (Факт vs План по днях тижня).
   - Кумулятивний графік спаленого жиру в кілограмах та грамах.
   - Динаміка ваги з 7-денним ковзним середнім (Moving Average) для згладжування коливань води.

5. **Безпечне Хмарне Збереження & Google Синхронізація:**
   - Вхід через **Google Акаунт (Firebase Auth + Cloud Firestore)**.
   - Опційна інтеграція з **Google Fit API** для автоматичного підтягування щоденних кроків та активних калорій.
   - Local-first архітектура: працює автономно та офлайн, зберігаючи дані в браузері, з можливістю миттєвого збереження в хмару під своїм обліковим записом Google.

## 🛠️ Запуск та Розробка

### Локальний запуск:
```bash
# Встановлення залежностей
npm install

# Запуск локального сервера розробки
npm run dev
```

### Збірка для деплою:
```bash
npm run build
```

---

## ☁️ Налаштування Google Auth (Firebase)

1. Перейдіть у [Firebase Console](https://console.firebase.google.com/) та створіть проєкт.
2. Увімкніть **Authentication** -> метод **Google**.
3. Створіть базу даних **Cloud Firestore**.
4. Скопіюйте конфігурацію Firebase Web App і вставте у вікні налаштувань додатку (або у файл `.env`).
